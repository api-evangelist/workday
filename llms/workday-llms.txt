# Workday

> Collection of Workday REST and SOAP APIs for human capital management, financial management, enterprise planning, analytics, and platform extensibility. Generated by API Evangelist from the apis.yml catalog (method: generated, 2026-06-20); no llms.txt is published on the provider's docs host.

Workday exposes tenant-scoped REST APIs under `/ccx/api/{service}/v1/{tenant}`, a standards-based SOAP Web Services (WWS) API, GraphQL and WQL query surfaces, Report-as-a-Service, and the Extend low-code platform. All access is OAuth 2.0 (authorization code) via a registered API Client per tenant.

## APIs
- [Workday HCM API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Workforce data, recruiting, talent, payroll
- [Workday Financial Management API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Accounting, procurement, expenses, revenue
- [Workday Recruiting API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Job postings, candidates, applications
- [Workday Time Tracking API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Time entry, timesheets, clock events
- [Workday Benefits API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Benefit elections, plans, dependents
- [Workday Absence Management API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Leave balances, time-off, leaves of absence
- [Workday Compensation API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Comp plans, scorecards, one-time payments
- [Workday Payroll API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Pay groups, inputs, tax rates, pay components
- [Workday Person API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Personal, contact, and org relationship data
- [Workday Performance Management API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Reviews, goals, feedback badges
- [Workday Talent Management API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Talent profiles, mentorships, succession
- [Workday Staffing API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Positions, job profiles, supervisory orgs
- [Workday Common API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Shared reference / lookup data
- [Workday Prism Analytics API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): Datasets, tables, data change tasks
- [Workday WQL API](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html): SQL-like querying of Workday data
- [Workday Report-as-a-Service (RaaS)](https://community.workday.com/api): Custom reports exposed as REST web services
- [Workday SOAP Web Services API](https://community.workday.com/api): WSDL/XSD across 55+ service areas
- [Workday Strategic Sourcing API](https://apidocs.workdayspend.com/): Sourcing events, awards, contracts, suppliers
- [Workday Adaptive Planning API](https://doc.workday.com/adaptive-planning/en-us/integration/managing-data-integration/api-documentation/understanding-the-adaptive-planning-rest-api/api-methods/brk1623709249507.html): Planning, accounts, dimensions, reports
- [Workday Extend API](https://www.workday.com/en-us/products/platform-product-extensions/app-development.html): Low-code custom app platform
